# Delivery — تطبيق الزبون (Flutter)

نفس قاعدة بيانات Firebase التي يستعملها الموقع delivery-dz.pages.dev.
كل رفع للكود على GitHub يبني ملف APK تلقائياً ويضعه في صفحة **Releases**.

- إشعار في الهاتف عند كل تغيّر في حالة طلبك (قبول المحل، خروج الموصّل، التوصيل) وعند رسالة من الموصّل، والضغط عليه يفتح متابعة الطلب.
