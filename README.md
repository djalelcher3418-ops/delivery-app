# Delivery — تطبيق الزبون (Flutter)

نفس قاعدة بيانات Firebase التي يستعملها الموقع delivery-dz.pages.dev.
كل رفع للكود على GitHub يبني ملف APK تلقائياً ويضعه في صفحة **Releases**.

- إشعار في الهاتف عند كل تغيّر في حالة طلبك (قبول المحل، خروج الموصّل، التوصيل) وعند رسالة من الموصّل، والضغط عليه يفتح متابعة الطلب.
- إذا طلب المحل وقتاً إضافياً للتحضير يصلك تنبيه بوقت الوصول الجديد.
- تنبيه «الموصّل قريب منك» قبل وصوله بقليل، مع المبلغ الذي تجهّزه.
- شريط «لا يوجد اتصال بالإنترنت» عند انقطاع الشبكة، وشريط «نسخة جديدة متاحة» مع زر تنزيل مباشر.
- عناوين محفوظة (البيت، العمل…) حتى 5 عناوين، تختارها بضغطة عند الطلب.
- الإعفاء من تحسين البطارية: شريط «اسمح للتطبيق بالعمل في الخلفية» حتى لا يقطع الهاتف عنه الشبكة فتتأخر التنبيهات.
- خدمة «نتابع طلبك» (إشعار ثابت) ما دام عندك طلب جارٍ، لتصلك التنبيهات والتطبيق في الخلفية.
